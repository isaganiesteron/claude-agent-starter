# Fact Checker

## When to Use
- On any AI-generated content before publishing or sharing
- On your own drafts, outlines, or talking points before presenting them
- On third-party articles, posts, or claims you want to evaluate
- As an automatic step in any content workflow before final output

## How to Execute

### Step 1 — Read and Inventory Claims
Read the full text carefully. Extract every factual claim — statistics, dates, names, product features, scientific statements, historical facts, quotes, and any assertion presented as fact. Create a mental or written inventory of all claims to verify.

### Step 2 — Classify Each Claim
For each claim assign a verification priority:
- **High** — specific numbers, statistics, dates, named sources, scientific claims
- **Medium** — general assertions about how things work, industry norms, best practices
- **Low** — widely accepted common knowledge unlikely to be wrong

Focus verification effort on high priority claims first.

### Step 3 — Verify Each Claim
For each high and medium priority claim:
- Search the web for authoritative sources
- Cross-reference at least 2 independent sources where possible
- Check if the claim matches what the original source actually says
- Note if the claim is accurate, misleading, unverifiable, or false
- For content based on a specific source (transcript, document), also verify against that source

### Step 4 — Generate Fact Check Report
Present a structured report:

**Overall Assessment** — one sentence summary of the content's factual reliability

**Claim by Claim Results:**
For each verified claim state:
- The claim as written
- Verdict: ✅ True / ⚠️ Mostly True / ❓ Unverifiable / ❌ False
- Brief explanation and source where relevant
- Suggested fix if the claim needs correction

**Summary Counts** — how many claims fall into each category

**Recommended Actions** — specific edits needed before this content is safe to publish

### Step 5 — Suggest Fixes
For any claim that is false, misleading, or unverifiable suggest:
- The corrected version of the claim
- A more defensible way to phrase it
- Whether to remove it entirely if it cannot be verified

## Definition of Done
The skill is complete when:
- All high and medium priority factual claims have been verified
- A full fact check report has been presented
- Specific fixes have been suggested for any inaccurate or unverifiable claims
- The content has been given an overall factual reliability assessment
